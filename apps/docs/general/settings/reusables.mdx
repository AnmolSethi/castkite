**Where:** Settings, **Sets** and **Caption & hashtag library**

<Note>
**Availability:** every Castkite plan.
</Note>

Two small features that remove most of the repetitive work from the composer.

## Sets

A set is a saved channel selection with its settings. If you always post to the
same six channels configured the same way, a set restores that in one click
instead of rebuilding it every time.

### Creating one

Settings, **Sets**, then build the arrangement in the composer and **Save
Set**.

While you are building a set, per-channel content editing is disabled:

> You can't edit networks when creating a set

Sets store the channel selection and its settings, not the text. The text is
what changes every time.

### Using one

When you start a new post, Castkite offers your sets first. Pick one, or
**Continue without set**.

### What sets are good for

- One set per client, so their channels come up together.
- One set per content type, when a video post and a text post go to different
  places.
- One set for "everything", so a company announcement is one click.

## Caption & hashtag library

The library holds the snippets you reuse: hashtag sets, captions, calls to
action, disclosures, a link to your newsletter. Everyone in your organisation
shares it.

### Saving a snippet

Settings, **Caption & hashtag library**, then add one. Give it a **Name**
(optional, for example *Launch week hashtags*) so it is easy to find, and
write the **Content**.

**Add to every new post automatically?** inserts that snippet whenever a
composer opens. Only turn it on for one snippet, or both will appear.

Once you have more than three snippets, a search box filters them by name and
content.

### Inserting one

**Insert from library** in the composer toolbar opens the library. Pick a
snippet and it is inserted at the cursor, then the library closes.

### A caution

An auto-added snippet goes into every new post on every channel, including
ones where it does not fit: a hashtag block on LinkedIn, a link on a channel
that strips links. If your snippet is platform-specific, insert it manually
instead, or detach the channel and adjust. See
[Global vs per-channel](/general/composer/global-vs-per-channel).
